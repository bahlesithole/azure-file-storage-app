# Azure File Storage App

A lightweight Azure File Storage application built using **React (Vite)** that demonstrates file handling, cloud integration concepts, and clean front-end architecture.

## 🎯 What Problem Does It Solve?

Storing files locally can make them difficult to access across different devices and applications.

This project explores how files can instead be stored and managed in the cloud using Azure, allowing an application to interact with remote storage rather than relying entirely on the user's local machine.

## 💡 Why I Built It

I wanted to understand what actually happens behind the scenes when an application uploads and retrieves files from cloud storage.

Rather than only learning Azure concepts theoretically, I wanted to build something that connected a frontend application to a real cloud service and allowed me to work with files programmatically.

This project gave me an opportunity to learn how cloud storage fits into a real application architecture.

## 🚀 Features
- Upload and manage files via Azure File Storage
- Modular file utilities for handling cloud operations
- Clean, responsive UI
- Built with modern React tooling (Vite)

## 🧠 What I Struggled With

The biggest challenge was understanding how a frontend application communicates with cloud storage.

I had to work through how files move from the user's browser to Azure, how the application interacts with the storage service, and how stored files can be retrieved and displayed again.

Working with Azure also forced me to think beyond just writing frontend code. I had to understand configuration, cloud resources, authentication and how different parts of an application communicate with external services.

## 📚 What I Learned

This project helped me understand the relationship between an application and cloud infrastructure.

I gained practical experience with:

- Connecting a web application to Azure services
- Working with cloud-based file storage
- Uploading and retrieving files programmatically
- Integrating external services into a React application
- Managing application configuration
- Understanding how frontend applications communicate with cloud resources
- Debugging integration issues between an application and a cloud service
- Using Vite and React to structure a modern web application

Most importantly, I learned that cloud development isn't just about deploying an application — it's about understanding how the application communicates with and depends on the infrastructure behind it.
